Installation

Installing our software is straightforward. Follow these steps:

npm install our-package
# or
yarn add our-package

After installation, verify everything is working correctly by running:

npx our-package --version

Configuration

Customize the behavior of our tool with these configuration options:

config.json

{
  "apiUrl": "https://api.example.com",
  "timeout": 5000,
  "retries": 3
}

Place this file in your project root directory to override default settings.
